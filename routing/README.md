# Routing Source Home

`routing/` preserves the retired predecessor source-home as v1 ABI and
transition evidence.

It is not a head mechanic. Shared OS Abyss operations such as Agon,
Experience, Checkpoint, Recurrence, Questbook, Antifragility, Boundary Bridge,
Release Support, RPG, and Titan route through `mechanics/<head>/`.

The G5 owner-switch receipt governed by `AOA-RT-D-0004` moved canonical
producer and ABI ownership to `aoa-sdk`. SDK-owned consumer-zero evidence
closed the compatibility window and retired the operational rollback role at
the final `v0.4.0` archive boundary. M1, M2, M3, and the retained source remain
historical transition evidence.
